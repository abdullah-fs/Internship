Topic 3 — Destructuring
Destructuring ka simple matlab hai: object ya array ke andar se values ko easily nikal kar variables mein store karna.


Destructuring JavaScript mein object ya array ke andar se values ko easily variables mein nikalne ka tareeqa hai. **Object destructuring** mein `{ }` use hota hai aur values property/name ke basis par milti hain, jaise `const { name, age } = user;`. **Array destructuring** mein `[ ]` use hota hai aur values position/order ke basis par milti hain, jaise `const [first, second] = fruits;`. React mein `useState()` ke saath array destructuring commonly use hoti hai, jaise `const [count, setCount] = useState(0);`.
